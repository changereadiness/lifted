# lifted.me — Operating Mind Concept (V0.2)

This is the first top-down visual pass that reframes Lifted from a quote generator into a portfolio-level intellectual property: a living operating philosophy.

## Core idea

**What survives experience becomes principle.**

Lifted is a sparse archive of:

- **Principles** — operating rules that have earned their place.
- **Observations** — recurring patterns not yet hardened into principle.
- **Sources** — traceable words and thinkers that sharpen the lens.
- **Get Lifted** — the original state-of-mind quote interaction, retained as one feature rather than the entire proposition.

## Visual language

The design deliberately echoes the broader portfolio without cloning another property:

- warm off-white `#F2F1ED`
- graphite `#202426` / `#151819`
- steel `#687278`
- restrained copper `#B56A3C`
- Manrope headings / Inter body
- oversized low-line-height hero type
- large negative space
- 2px copper scroll progress
- sticky blurred header
- subtle reveal-on-scroll
- minimal borders and no decorative imagery

## Important

The **principles and observations in this build are seed copy for structure and visual testing**, not a declaration that the operating philosophy is finished. They should be replaced/refined through the next editorial pass.

The existing verified quote seed remains in `quotes.js`. The provenance standard stays unchanged: no anonymous or weakly attributed quote should enter production.
